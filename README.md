### Engineering Profile

I am a **Software Engineer** specializing in full-stack web architectures, reactive mobile applications, and **Retrieval-Augmented Generation (RAG)** workflows. My focus is on writing production-ready, performant code, building secure backend systems, and packaging complex AI models into scalable user interfaces.

- **Focus Areas:** Scalable Microservices, Vector Search, MLOps Pipelines, Responsive UI/UX.
- **Academic Foundation:** Computer Science at **COMSATS University Islamabad (Abbottabad Campus)**.
- **Core Stack:** TypeScript, React, Next.js, Node.js, Express, MongoDB, Docker, Python.
